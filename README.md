# 💳 Credit Card Fraud Detection System

## 📌 Overview

This project is a machine learning-based fraud detection system that identifies whether a transaction is legitimate or fraudulent.

## 🚀 Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Model training with and without synthetic data
* Performance comparison (Precision, Recall, F1 Score)
* ROC Curve & Confusion Matrix
* Interactive Streamlit Web App

## 📊 Dataset

The dataset contains anonymized transaction features (V1–V28), Time, Amount, and Class.

## 🧠 Model Used

* Logistic Regression / Random Forest (jo use kiya hai wo likh)
* Improved using synthetic data

## 📈 Results

* High accuracy in detecting normal transactions
* Improved recall after applying synthetic data
* AUC Score ≈ 0.98

## 🌐 Deployment

You can run this app using ngrok or Streamlit Cloud.
